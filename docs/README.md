# Documentation

## Plans

Implementation plans for project features and improvements. Each plan lives in its own
directory under [`.planners/plans/`](../.planners/plans/) as `<NNN>-<slug>/plan.md`, with
YAML frontmatter tracking status, branch, and timestamps.

The generated index — every plan with its status, conclusion date, and PR — is
[`.planners/README.md`](../.planners/README.md).
